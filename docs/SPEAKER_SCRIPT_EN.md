## 0:00–0:30 — SƏDD

Every AI prompt can look harmless in isolation. A trusted employee can disclose a protected document a few words at a time.

SƏDD connects behavioral evidence to an enforceable transfer decision, then checks transport evidence. Today we use invented documents, real local delivery, and a portal that returns a real local-model answer only after admission. The OpenAI route is an optional alternative.

## 0:30–1:05 — Small excerpts accumulate

Our controlled document permits limited quotations. The first excerpt reaches the receiver. The second also passes. Together, a third would exceed the cumulative allowance, so the gateway blocks it before sending.

We count distinct observed evidence, including active reservations and uncertain delivery. Four-word sequences and anchored short tokens have separate denominators. These ratios describe textual exposure. They are not a percentage of document bytes reconstructed.

Restricted material and recognized credentials follow a hard prohibition regardless of behavior.

## 1:05–1:45 — Architecture

We build personal and eligible peer baselines from earlier user-days and train a genuine Isolation Forest. Actual application accesses feed a separate visible live rule.

The server supplies identity and context. The content engine checks registered fragments and structured credentials. SQLite reserves exposure atomically before the original text reaches a separate local HTTP receiver.

A validated receipt binds the subject, request identifier, original digest and byte count. A policy decision and a delivery outcome are different facts.
